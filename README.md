# Quản lý KSNK – Bệnh viện Ngoại khoa 115 Nghệ An
Mở **BAT_DAU.html** trong trình duyệt để xem hướng dẫn tiếng Việt. Mã nguồn Next.js nằm ngay tại thư mục này. GitHub lưu mã, Vercel chạy ứng dụng và Supabase lưu tài khoản, phiên đăng nhập, dữ liệu nghiệp vụ và tệp.

Dùng Node.js 24. Sao chép .env.example thành .env.local, điền cấu hình của bản sao, chạy npm ci rồi npm run dev. Để kiểm tra bản phát hành, chạy npm run build và npm start.

supabase/CAI_DAT.sql là tập lệnh cài đặt đầy đủ cho một Supabase mới. Hướng dẫn cũ trong docs/ và legacy-apps-script/ chỉ phục vụ đối chiếu nghiệp vụ. Dùng BAT_DAU.html cho việc cài đặt và phân quyền phiên bản này.
